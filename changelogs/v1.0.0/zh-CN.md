# SF6Koishi 版本日志 - v1.0.0

发布日期: 2026-07-15

SF6Koishi 首个正式版本发布！为《街头霸王 6》玩家提供全方位的机器人助手服务。

## 核心功能

### SF6 招式帧数查询 (koishi-plugin-sf6-frame-data)
- **招式卡片渲染**：基于 Puppeteer 将招式发生帧、持续帧、硬直差、伤害、打打击判定等数据渲染为高清图片卡片。
- **智能别名匹配**：支持角色名称（如 `豪鬼` / `Akuma` / `隆` / `Ryu`）及招式别名（如 `5hp` / `236p` / `SA3`）模糊匹配。
- **动态 Manifest 缓存**：自动同步 Scouter API 最新的角色列表与版本定义。

### 对局回放自动录制 (koishi-plugin-sf6-replayer)
- **回放提交**：支持输入 9 位回放代码（如 `12A34B567`）提交后台极速录制任务。
- **主动通知提醒**：录制完成并在 B 站/YouTube 审核通过后，主动在群聊或私聊中艾特用户并附带视频播放链接。
- **全局去重与共享**：相同回放 ID 全局仅录制一次，多人重复提交自动转为订阅推送模式。

### SF6 助手与智能引导 (koishi-plugin-sf6-assistant)
- **功能菜单**：支持 `功能` / `菜单` / `帮助` / `features` / `menu` 唤起主菜单。
- **@Bot 触发引导**：在群组中艾特机器人时提供友好功能的兜底菜单引导。
- **多语言支持**：内置 `zh-CN`（简体中文）与 `en-US`（英文）国际化框架。
