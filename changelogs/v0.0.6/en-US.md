# SF6S Changelog - v0.0.6

## Added

- **Jump Command Parsing in Move Query**: The move query feature now supports parsing jump commands. Users can input them via number keys, words, or the letter 'j', making it easier for users to find and input the corresponding moves.

## Improved

- **Interactive Experience Optimization**: Optimized the interactive experience, improving usability and convenience.
