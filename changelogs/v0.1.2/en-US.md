# SF6S Changelog - v0.1.2

## Added

- **Plus-on-Block Move Queries**: Use commands such as `招式 肯 加帧` to view a character's moves with positive block advantage (excluding zero-frame moves).
- **Arjun Move Data**: Added support for querying Arjun's moves and frame data.

## Improved

- **Menu Display**: Refined the menu layout to make feature entry points and usage guidance clearer.
