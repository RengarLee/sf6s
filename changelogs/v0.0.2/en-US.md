# SF6S Changelog - v0.0.2

## Added

- **Official Move Notes Integration**: Querying move frame data and hitboxes now returns official Capcom developer notes and adjustment details for full move insights.
- **Detailed Character Hitbox Links**: Move query cards and text responses now include direct Ultimate Frame Data links to the corresponding character's detailed hitbox pages for frame-by-frame visual analysis.
  - 🙌 Special thanks to [Ultimate Frame Data](https://ultimateframedata.com/) for providing hitbox and frame data support to the FGC community
- **Smart Candidate Character Suggestions**: When a queried move or character name is not an exact match, the bot automatically performs fuzzy matching and suggests candidate characters to improve search fault tolerance.
