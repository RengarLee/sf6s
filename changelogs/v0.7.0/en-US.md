# SF6S Changelog - v0.7.0

## Added

- **Player Account "Bind" Feature**: Supports sending "`绑定 <CFNID>`" to link the current account with an official SF6 CFN ID. Once bound, subsequent profile queries, match statistics, and milestone notifications do not require re-entering the ID.
- **Account "Unbind" Feature**: Supports sending "`解绑`" to unbind the currently linked CFN ID with one click, making it convenient to switch or re-link accounts at any time.
- **Fighter "Profile" Query Command**: Supports sending "`资料`" to quickly retrieve a player's profile card, including LP/MR points across modes, main characters, title, rank, and other core information.
- **Player "Match Stats" Panel Query**: Supports sending "`战绩`" to obtain visual match statistics, intuitively displaying recent win rates, ranked performance, and character-specific match data.
- **Milestone "Victory Announcement" Rendering & Push**: Automatically generates and pushes elegant visual graphics cards during key moments such as rank promotions or peak achievements, making it easy to share highlight moments (*Requires prior CFN ID "binding" to use and receive push notifications*).
