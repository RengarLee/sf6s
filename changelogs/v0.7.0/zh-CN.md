# SF6S 版本日志 - v0.7.0

## 新增

- **新增账号「绑定」功能**：支持发送「`绑定 <CFNID>`」将当前账号与 SF6 官方 CFN ID 关联，绑定后后续查询资料、战绩与喜报推送无需重复输入 ID，绑定后可以跨群使用。
- **新增账号「解绑」功能**：支持发送「`解绑`」一键解除当前绑定的 CFN ID，方便随时更换或重新关联账号。
- **新增「资料」查询命令**：支持发送「`资料`」快捷调取玩家个人名片，包含各模式 LP/MR 积分、主玩角色及称号段位等核心信息。
- **新增「战绩」面板查询**：支持发送「`战绩`」获取可视化战绩统计，直观展示近期胜负率、排位表现与分角色对局数据。
- **新增里程碑「喜报」渲染与推送**：支持在玩家达成段位突破、重战巅峰等关键时刻时，自动生成并发送精美的图文喜报卡片，轻松分享荣耀高光时刻（*需先完成 CFN ID「绑定」后方可使用与自动接收推送*）。
