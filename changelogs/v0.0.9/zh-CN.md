# SF6S 版本日志 - v0.0.9

## 新增

- **新增「切磋」查询功能**：支持查找以本群为常用群的已绑定玩家，按角色、段位或 MR 范围筛选，方便寻找练习对手。查询结果仅提供玩家资料，约战请自行联系。
  - 🙌 特别感谢 QQ 焕冥, QQ 悠哈 提供的建议
- **新增「悲报」推送功能**：当玩家 MR 跌破关键分段或回升后再次失守时，自动生成并推送图文悲报卡片，记录排位路上的起起落落（需先完成 CFN ID 绑定）。
- **新增「喜报」「悲报」推送开关**：支持发送 `喜报 开启`、`喜报 关闭` 或 `悲报 开启`、`悲报 关闭`，分别控制段位突破、重返高点等喜报，以及 MR 跌破关键分段时的悲报自动推送；单独发送 `喜报` 或 `悲报` 可查看对应的当前设置。喜报仅向玩家的常用群推送。
  - 🙌 特别感谢 QQ 悠哈 提供的建议

> **常用群说明**：机器人会根据玩家在群内使用机器人的情况，自动识别其常用群。玩家需要经常在本群使用机器人，才会出现在本群的切磋查询结果中，并在开启喜报后于本群收到喜报推送。
