# SF6S Changelog - v0.0.3

## Added

- **Move Cancel Information Display**: Move query results now display cancel property and route information, clearly showing which move types a given move can be canceled into (such as Special Moves, Super Arts SA1/SA2/SA3, Drive Rush, etc.) for accurate combo planning and cancel route analysis.
