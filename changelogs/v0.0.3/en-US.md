# SF6S Changelog - v0.0.3

## Added
- **Move Cancel Information Display**: Move query results now display cancel property information, clearly showing which move types the current move can be canceled into (such as Special Moves, Super Arts SA1/SA2/SA3, Drive Rush, etc.).
  - 🙌 Special thanks to QQ 焕冥, QQ 悠哈 for the suggestions

## Removed
- **Hitbox Link Prompt Removal**: Removed the feature that prompts Hitbox links during move queries.
  - 🙌 Special thanks to QQ 焕冥 for the suggestion
