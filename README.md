# SF6S 机器人功能一览

## 核心功能

- **SF6 招式帧数查询**：支持通过角色名（如豪鬼、Akuma）与招式别名（如 5hp、236p、OD升龙）查询招式发生帧、硬直差、判定与伤害数据以及招式取消信息（可被哪些类型的招式取消），并渲染为高清图片卡片；同步支持展示官方招式笔记与角色详细攻击框（Hitbox）网站链接。
  - 🙌 特别感谢 QQ 太简单, QQ 焕冥, QQ 马肯博, QQ 悠哈, QQ 　, QQ 路德维C, QQ aaa 乐, QQ balance 提供的数据支持

<p align="center">
  <img src="https://raw.githubusercontent.com/RengarLee/sf6s/main/changelogs/v0.0.1/move.jpg" alt="招式查询" width="500" />
</p>

- **对局回放录制与主动通知**：支持提交 9 位游戏内回放 ID 触发后台视频录制，视频发布 B 站后主动艾特提交者并附带播放链接；视频评论中自动附带“丝血反杀”精彩时刻时间节点提示。

- **回放数据快速分析**：提供专门的分析命令，可对对局回放数据进行快速解析与多维度统计，帮助玩家快速掌握对战细节。

- **服务器升级主动提示**：当服务器进行版本升级或系统维护时，向用户提醒，确保服务状态实时感知。
  - 🙌 特别感谢 QQ 悠哈 提供的建议

  <img src="https://raw.githubusercontent.com/RengarLee/sf6s/main/changelogs/v0.0.1/update.png" alt="服务器升级提示" width="500" />
</p>

- **友好话术与引导提醒**：未识别到角色或招式名时提供智能角色模糊匹配与候选推荐；在群聊艾特机器人的无输入场景下提供结构化提示话术与菜单指引。
